# Edmonton Snow Removal

Commercial snow and ice management website. Static single-page site — no build step.

## Deploy to Netlify
1. Push this folder's contents to a GitHub repo.
2. Netlify → Add new site → Import an existing project → pick the repo.
3. Build command: *(leave blank)*  ·  Publish directory: `.`
4. Deploy.

## Files
- `index.html` — the entire site (self-contained)
- `netlify.toml` — Netlify build + security headers
- `robots.txt` / `sitemap.xml` — replace `YOUR-DOMAIN.com` with the live domain
